La opción por defecto: buen balance de CPU/RAM/disco para un agente trabajando solo (shell, tests, git). Es lo que recomendamos para empezar.

Misma idea que Estándar pero en arquitectura ARM — más barata por el mismo uso. Anda bien para MCP Terminal; si vas a correr algo muy específico compilado solo para x86, confirmá compatibilidad antes de elegirla.

Más RAM por núcleo que la Estándar — pensada para varios agentes en paralelo en el mismo pod, o tareas que consumen memoria (builds grandes, test suites pesados).

CPU dedicada (no compartida con otros clientes) — para cargas sostenidas de mucho cómputo. Es la más cara; no hace falta para el caso de uso típico de un agente de código.
